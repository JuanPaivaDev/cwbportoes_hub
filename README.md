# CWB Portões Hub

Protótipo funcional de uma plataforma de gestão de equipes de campo para a CWB Portões Eletrônicos.

## Estado atual

Esta versão é um protótipo front-end 100% mockado, criado para validação comercial e definição do produto antes da implementação do backend, banco de dados e aplicativo de campo.

## Módulos incluídos

- Dashboard executivo e operacional
- Central de operações com mapa e técnicos
- Agenda semanal de ordens de serviço
- Kanban de ordens de serviço
- Técnicos e clientes
- Produtos e materiais
- Serviços
- Orçamentos com geração de PDF
- Unidades / franquias
- Financeiro e relatórios
- Mock do aplicativo do técnico

## Protótipo

Abra `index.html` diretamente no navegador. O protótipo utiliza alguns recursos externos via CDN (mapa, fontes, ícones e biblioteca de PDF), portanto a demonstração funciona melhor com acesso à internet.

## Próxima etapa

O objetivo do repositório é servir como referência visual e funcional para o Codex transformar gradualmente o protótipo em uma aplicação real, preservando os fluxos e a identidade visual já aprovados.
